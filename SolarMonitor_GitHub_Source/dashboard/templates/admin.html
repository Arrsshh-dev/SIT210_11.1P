System configuration

Mail transport and security

SMTP host, port, username, password and sender address are configured through environment variables on the Raspberry Pi. They are not stored in browser code or displayed in this panel. The alert worker emails active technician accounts (or the explicit recipient override configured by the system owner).

Hardware-fault alerts require a fault to remain active for five minutes. Recovered faults cancel pending alerts. ML anomaly predictions are informational and do not trigger hardware-fault emails.

Use HTTPS for remote access and set SOLARTRACK_HTTPS=1 behind the trusted HTTPS tunnel or reverse proxy.
